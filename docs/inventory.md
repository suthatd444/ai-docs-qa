# Inventory and units

Each project contains units of three types: plots, apartments and shops. Plot sizes are listed in marla and square feet. One marla equals 272.25 square feet.

A unit status moves from Available to Reserved when a token is received, and to Sold once the down payment is approved. Units can be marked Lost if the customer cancels.

Photos and videos for each unit are stored in S3 and shown on the unit page.
